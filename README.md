# Buraco House

Crie uma aplicação web completa, moderna e responsiva para uma loja/comunidade de Cobblemon.

IMPORTANTE:

- A imagem de referência que forneci serve APENAS como inspiração visual.

- NÃO copie o site, identidade, textos, logotipo ou conteúdo da imagem.

- Crie uma identidade visual própria para o meu projeto.

- O site deve funcionar perfeitamente em computador e celular.

- Não quero apenas um mockup. Quero uma aplicação funcional, com navegação real entre páginas e estrutura preparada para banco de dados e painel administrativo.

- Todas as informações que forem alteráveis devem ser estruturadas de forma que futuramente possam ser gerenciadas pelo administrador sem precisar editar o código.

==================================================

1. CONCEITO DO SITE

==================================================

O site será uma plataforma de vendas e eventos relacionada a um servidor de Cobblemon.

A finalidade é centralizar:

- informações da loja;

- colaboradores;

- leilões;

- ranking de compradores;

- novidades;

- eventos futuros;

- sistema de sorte/roleta;

- contatos através do Discord.

O público principal são jogadores do servidor de Cobblemon.

O site deve transmitir uma aparência de:

- comunidade gamer;

- loja premium;

- organização;

- confiança;

- exclusividade;

- temática Pokémon/Cobblemon;

- tecnologia moderna.

Não deixe o site infantil demais.

Quero uma aparência profissional, semelhante a uma plataforma gamer moderna.
